在りし日の唄 - GitHub Pages用スターター

1. index.html をGitHubリポジトリのルートにアップロードします。
2. assets フォルダを作成し、公開権利のある音源を song.mp3 という名前で入れます。
3. GitHubの Settings > Pages で Branch: main / Folder: /(root) を選び、Saveします。
4. 公開URLを開いて再生を確認します。

注意:
- この版はProtoPieデータを自動変換したものではなく、画面と基本操作をWeb用に再現するための土台です。
- 現在のジャケット画像は仮表示です。画像を使う場合は assets/cover.jpg などとして追加し、index.html のカバー部分を変更してください。
- 音源や画像は、公開してよい権利のあるものを使用してください。
- 前/次ボタンは現在、再生位置を先頭に戻す仮動作です。複数曲への切り替えは未実装です。
